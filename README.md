> **Альфа.** Работает у автора на Windows каждый день, но ставится руками и может
> упасть на вашем железе. Ошибки и пожелания — в [Issues](https://github.com/life332/apskeyl/issues).

Десктопная программа: добавляешь видео в библиотеку → кликаешь → **«Улучшить»** →
выбираешь **что** (Full HD / 2K / 4K) и **как** (какой моделью) → в очередь. Всё считается
на твоей видеокарте, ничего никуда не отправляется.

![скриншот](docs/screenshot.png)

## Что умеет

- **Проба перед рендером** — 1 кадр за секунды или 10-секундный клип за ~1–2 минуты,
  сравнение «до/после» шторкой и A/B. Смысл: увидеть результат **до** того, как отдать
  видеокарте часы работы. Проба берётся с самой динамичной сцены, а не с заставки.
- **Честное время.** Прогноз считается по твоим же замерам и уточняется после каждой
  пробы. Если модель займёт 20 часов — это будет написано жёлтым до старта, а не выяснится утром.
- **Два движка.** Vulkan (любая видеокарта, модели `.param/.bin`) и опционально
  PyTorch+CUDA+TensorRT (NVIDIA) — в **2.5 раза быстрее** на тяжёлых моделях и читает
  `.pth/.safetensors` напрямую, то есть открывает почти весь OpenModelDB.
- **Каталог моделей 🧭** — 670+ моделей с OpenModelDB и зеркал HuggingFace: описание, автор,
  лицензия, примерная скорость; 300 из них ставятся одной кнопкой с проверкой sha256.
  Раз в 4 дня сам проверяет новинки.
- **Оценка качества на твоих кадрах** — LPIPS на нативных записях из твоей библиотеки,
  чтобы рейтинг моделей отражал твой материал, а не чужие картинки.
- **Очередь, которая переживает всё:** сегментный конвейер (пик временных файлов ~10 ГБ
  вместо 136 ГБ на 10-минутное 4K), сторож диска, сторож зависаний, докручивание после
  убийства процесса, проверка длительности перед финальной записью.
- **Быстрый путь без нейросети** (lanczos + резкость + NVENC) — минуты вместо часов, когда
  источник и так чистый.
- Интерфейс на русском / украинском / английском. Кодек libx264 или HEVC NVENC.

## Честные цифры

Замерено на **RTX 3080 Ti 12 ГБ + i7-13700K**, вход 1080p, цель 4K, 10-минутное видео:

| Модель | с/кадр | 10 мин 1080p → 4K | Для чего |
|---|---|---|---|
| ⚡ без нейросети (lanczos+cas) | ~0.02 | **≈ 4 мин** | чистый источник |
| `realesr-animevideov3` ×2 | 0.21 | ≈ 1.1 ч | аниме, мультики |
| `realesr-general-x4v3` | 0.58 | ≈ 2.9 ч | баланс |
| `4x-UltraSharp` — движок Vulkan | 4.6 | ≈ 23 ч | максимум детали |
| `4x-UltraSharp` — движок TensorRT | **1.84** | **≈ 9 ч** | то же, ×2.5 быстрее (SSIM 0.997 к Vulkan) |

Другие видеокарты — другие цифры: программа замерит твои сама после первой пробы.

## Честные ограничения

- **На чистом 1080p нейросеть почти бесполезна:** +12 % резкости и +22 % ореолов
  по сравнению с хорошим lanczos. Она сияет на ≤720p, на старом и пережатом видео.
  Программа сама подскажет, нужна ли нейросеть для конкретного файла.
- **Мерцание.** Покадровые GAN-модели могут «дышать» на движении. Лечится частично
  (кинозерно, мягкое смешивание); темпоральных моделей здесь нет.
- **Только Windows 10/11**, нужен WebView2 (в Windows 11 есть, в 10 — ставится с Edge).
- **Диск.** Во время рендера 4K временные кадры занимают десятки гигабайт. Данные держи на
  большом диске — программа спросит при первом запуске.
- **Лицензии моделей.** Самые красивые модели (UltraSharp, Siax, LSDIRplus…) —
  **некоммерческие** (CC BY-NC-SA). Для коммерческой работы бери модели Real-ESRGAN (BSD).
  Подробно — [THIRD_PARTY.md](THIRD_PARTY.md).

## Установка

Нужен [Python 3.11+](https://www.python.org/downloads/) (при установке поставь галку
*Add to PATH*). Дальше в PowerShell:

```powershell
git clone https://github.com/life332/apskeyl.git
cd apskeyl
powershell -ExecutionPolicy Bypass -File tools\setup.ps1
tools\apskeyl.cmd
```

`setup.ps1` создаёт лёгкое окружение (~60 МБ) и скачивает ffmpeg (~90 МБ) и
realesrgan-ncnn-vulkan с базовыми моделями (~45 МБ) в `tools\bin\`. Вне папки программы
ничего не пишется. Первый запуск спросит, где держать данные.

**Движок 2 (NVIDIA, опционально, ~8 ГБ):**

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup_engine2.ps1
```

После этого модели `.pth` из каталога 🧭 ставятся одной кнопкой, а тяжёлые модели
считаются через TensorRT.

Если ffmpeg / realesrgan уже есть — `setup.ps1 -SkipTools` и переменная
`APSK_TOOLS=<папка с бинарниками>` (или `tools_dir` в `apskeyl.json`).

## Как пользоваться

1. **Библиотека** → «Добавить видео» (или брось файлы в папку `inbox` внутри папки данных).
2. Клик по видео → справа паспорт файла и рекомендация «нужна ли нейросеть».
3. **Улучшить** → выбери цель (Full HD / 2K / 4K — плитки честно показывают, что реально
   получится для этого файла) и модель.
4. **Проба 1 кадра** → если нравится, **10 секунд** → если нравится, **в очередь**.
5. Готовое — во вкладке «Готово» и в папке `out` (папку можно поменять в 🛠).

## Как это устроено

`app/server.py` — FastAPI на `127.0.0.1:8391`, живёт отдельным процессом (закрыл окно —
рендер продолжается, сам гаснет через 30 минут простоя). `app/desktop.py` — окно на
pywebview/WebView2. `app/jobs.py` — очередь и сегментный конвейер. `app/engine.py` —
команды ffmpeg/рушия. `app/engine2_runner.py` — PyTorch/TensorRT движок в отдельном
окружении. `app/scout.py` — каталог моделей. `web/` — интерфейс без фреймворков.
